# عُلِم: المنصة العربية لتوثيق العلوم البرمجية

**عُلِم** هو مشروع تقني مفتوح المصدر يسعى لتأسيس مرجع أكاديمي مكتوب لعلوم الحاسوب باللغة العربية. يرتكز المشروع على فلسفة "التعلّم عبر التوثيق المنظم"، توفيراً لبديل معرفي رصين يتجاوز عشوائية المحتوى المرئي، ويقلل من الاعتماد الكلي على المصادر الأجنبية في مراحل التأسيس والتطوير.

تم بناء المنصة باستخدام إطار عمل ([Docusaurus](https://docusaurus.io/)) من شركة Meta (Facebook سابقاً) لضمان السرعة، الكفاءة البرمجية، ومعايير أرشفة المحتوى المتطورة.

![صورة مستودع عُلِم](./static/img/open%20graph.png)

---

## 🏛 البنية التقنية للمشروع

تعتمد المنصة منظومة تقنية متكاملة تضمن استدامة المحتوى وقابليته للتوسع:

- **إطار العمل الأساسي:** إطار عمل (Docusaurus) لتوليد المواقع الساكنة.
- **بنية الواجهة:** مكتبة (React.js) لدعم المكونات التفاعلية.
- **تنسيق المحتوى:** لغتي (MDX و MD) اللاتي تدمجن بين بساطة التحرير وقوة برمجيات React.
- **نظام التنسيق:** (CSS3 و TailwindCSS) مع دعم كامل لخصائص القراءة من اليمين إلى اليسار.

## 🚀 البدء السريع وإعداد البيئة المحلية

لتشغيل المنصة على جهازك الشخصي بغرض التطوير أو المعاينة، اتبع الخطوات التالية:

### المتطلبات التقنية

- تثبيت بيئة (Node.js) بإصدار حديث.
- مدير حزم مثل (npm).

### خطوات التشغيل

استنساخ المستودع من المنصة:

```bash
git clone https://github.com/binhunaish/olem.ar.git
```

الانتقال إلى مجلد المشروع:

```bash
cd olem.ar
```

تثبيت الاعتمادات البرمجية اللازمة:

```bash
npm install
```

تشغيل خادم التطوير المحلي للمعاينة الحية:

```bash
npm start
```

سيكون الموقع متاحاً للمعاينة الفورية عبر الرابط المحلي: `http://localhost:3000/olem.ar`.
قد يتغير منفذ الموقع في حال انشغار المنفذ 3000.
