# دليل مجلد docs

هذا الملجد هو الحاوي الرئيسي لجميع الوثائق في مشروع عُلِم.

## كيفية صناعة وثائق

لصناعة وصائق (docs) كل ما عليك فعله هو انشاء مجلد يبتدئ باسم الوثائق وينتهي بـ`-doc`. على سبيل المثال:

```
python-doc
```
حيث يعرف الخادم بوجود وثائق عن طريق ملحق `-doc`، ويمكنك جعل الاسم كما شئت.

## كيفية الكتابة

تعتمد الكتابة على انشاء ملفات `.md` مثل `intro.md` حيث تمتلك الحرية في كتابة الاسم وثم لحقه بـ`.md`.

كي تنسق الصفحات ستحتاج الى الى تعلم اجراءات Markdown ومن فهم [اجراءات Markdown في Docusuarus تحديداً](https://docusaurus.io/docs/markdown-features).

## مكان حفظ الموارد

يجب عليك حفظ موارد الوثائق مصل الصور والمواقع داخل مجلد الوثائق وتحديداً داخل مجلد `assets`.

## العنوَنة

وهي بناء العناوين، يجب عليك معرفة طرق العنونة في مشروع عُلِم:

1. **الترويس**

وهي وضخ العلومات في رأس الملف عن طريق اجراءات Markdown:

```
---
title: my hello page title
description: my hello page description
tags: 
    - react
    - docs
    - jaascript
---
```
وضع الترويس أول الملف مهم للغاية، قد لا يعمل إن قدّمت شيئاً عليه.

2. **عنوان الملف او اسم المجلد**

وهنا اعني اسم المجلد الذي يسبق ملحق `-doc` كما شرحنا في [كيفية صناعة وثائق](#كيفية-صناعة-وثائق) في الأعلى، او اسم ملف `index.md` الذي يكون مقدمة الوثيقة.

3. **ملف `_category_.json`**

لا اريد شرحه، [اقرأ المزيد هنا](https://docusaurus.io/docs/sidebar/autogenerated#category-item-metadata).
